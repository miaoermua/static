# static

对博客中的静态资源如图片，视频，文件；此仓库更方便整理同步，并且对他人开放使用其资源。

例如使用公益 CDN 引用资源 `https://fastly.jsdelivr.net/gh/miaoermua/static@main/` 你也可以使用其他镜像源引用。

部分文件资源版权来自网络不属于 @miaoermua 喵二即作者，使用的素材大概率也没有经过许可，如果仓库内文件涉及到你的版权，请联系我进行删除。
